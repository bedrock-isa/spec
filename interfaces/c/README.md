# Bedrock C target interface

This domain owns compiler builtins, target-specific C types, and public target
header contracts. It is deliberately separate from `../../abi/c/`: the C ABI
governs binary interoperability, while this directory governs
source/compiler-facing interfaces. `documents/` is normative; public headers
are generated by the `c-target-headers` artifact.

Structured definitions live below `intrinsics/groups/<group>/intrinsics` and
`types/groups/<group>/types`. Group IDs determine projected header names;
definitions never store header filenames. Local logical references retain the
`<owner>.<path>.<element>` form, while cross-domain references use
`<domain>:<local-reference>`, for example
`isa:FP.instructions.FCLASS`.
