# Bedrock

Bedrock specifies a 64-bit instruction set architecture, a 64-bit ELF
environment, and an LP64 C ABI.

Install the Python dependencies and validate the authored specification:

```sh
python3 -m pip install -r requirements.txt
python3 -m engine check
```

Generated artifacts are written below `output/`.
