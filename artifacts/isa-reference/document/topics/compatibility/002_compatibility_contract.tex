\subsection{Compatibility Contract}

This section defines the default compatibility contract for (:term:base.terms.reserved:) (:term:base.terms.field|plural:) and optional features. A later section
may narrow one of these defaults for a specific structure, but it must say so explicitly.

This manual treats (:term:base.terms.reserved:) and unallocated encodings as one architectural category: software must not depend on their
value, decode result, or behavior.
