\subsection{Reserved Fields}
Architected registers and architectural memory structures use these defaults unless their defining section gives a
narrower rule.

Software-defined (:term:base.terms.field|plural:) form a separate software-use category. Software may store values in them, and hardware
ignores them except where the containing structure explicitly says otherwise.
