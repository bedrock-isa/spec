\subsection{Paging Stage}

Paging is enabled by \texttt{PTCR.PE} and translates the linear address produced by segment pre-translation. Before
the walk can produce a translation, the linear address must be canonical for the mode selected by
\texttt{PTCR.LA57}. A noncanonical address raises \texttt{PAGE\_FAULT}. With paging disabled, the memory system uses
the linear address directly.

Each page-table level uses a nine-bit address field to select one of 512 64-bit entries in a 4-KiB table page. For a
table-page base address (B) and index (i), the selected entry is at (B + 8i). The walker starts at the physical
table page named by \texttt{PTCR.root\_page}. Every selected entry above L1 points to the next table page, and the
selected L1 entry is the leaf PTE. Its physical frame number is combined
with linear-address bits \texttt{11..0} to form the memory-system address. The leaf \texttt{AT} bit determines
whether that value is a byte address or a slot address:

\[
  \mathit{memory\_system\_address} = (\mathit{leaf\_PFN} \ll 12) + \mathit{linear}[11:0].
\]

The walker validates every consumed entry and accumulates its permissions while descending toward L1. The leaf PTE
supplies the final frame number and memory attributes. The detailed entry-validity, permission, accessed, and dirty
rules are specified under Page-Table Entry Format. At each consumed level, result priority is not-present first,
structural validity second, and accumulated permission third; the walker resolves those results before consuming a
lower level.

\subsection{LA48 Four-Level Paging}

When \texttt{PTCR.LA57} is zero, bits \texttt{63..48} of the linear address must equal the sign extension of bit
\texttt{47}. Bits \texttt{47..39}, \texttt{38..30}, \texttt{29..21}, and \texttt{20..12} select the L4, L3, L2,
and L1 entries respectively. The twelve low bits are carried unchanged as the offset within the translated 4-KiB
page. The L4 table is the root table named by \texttt{PTCR.root\_page}.

\subsection{LA57 Five-Level Paging}

When \texttt{PTCR.LA57} is one, bits \texttt{63..57} of the linear address must equal the sign extension of bit
\texttt{56}. Bits \texttt{56..48} select an additional L5 entry, whose PFN identifies the L4 table. Bits
\texttt{47..12} then drive the same L4-through-L1 walk used by LA48, and bits \texttt{11..0} remain the page offset.
The L5 table is the root table named by \texttt{PTCR.root\_page}.
