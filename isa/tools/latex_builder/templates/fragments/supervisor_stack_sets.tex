\subsection{Supervisor Stack Sets}
The IVT entry SN field selects one of four supervisor stack sets. Each set contains a validated 64-bit stack-segment
image and a raw 64-bit stack pointer. Interrupt, exception, NMI, and double-fault delivery all use the selected pair.

Delivery validates the selected segment image before exposing the supervisor transition. Failure to establish the
selected stack or to store the entry frame enters the double-fault delivery path. A failure while delivering the
double fault follows the platform's terminal fault policy.
