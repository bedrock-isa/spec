The following quantities are evaluated mathematically without 64-bit truncation:
\[
\begin{aligned}
\mathit{base}  &= \mathit{base\_page}\times4096,\\
\mathit{span}  &= \mathit{m}\times 2^{\mathit{e}}\times4096,\\
\mathit{limit} &= \mathit{base}+\mathit{span}.
\end{aligned}
\]
A segment image with \texttt{m=0} is a valid disabled image. An enabled image is valid only when
\(\mathit{limit}\leq 2^{64}\). The disabled, translated-window, and bounds-only address checks and their fault
rules are defined in \hyperref[section:segment-pre-translation]{Segment Pre-Translation}.
