Freestanding C behavior is defined by the active C ABI profile and the ELF ABI
profile it names.

\subsection{Execution Boundary}
Execution-boundary ownership, entry state, zero-fill policy, and OS handoff
rules are supplied by the ABI specification.

\subsection{TLS and OS ABI Boundary}
TLS and OS boundary rules are supplied by the ABI specification.

\subsection{C Linkage}
C linkage and direct-call relocation rules are supplied by the ABI
specification. Direct C calls use @DIRECT_CALL_RELOCATION@.
