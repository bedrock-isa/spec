\subsection{Reading an Instruction Description}
Each instruction description starts with assembler syntax and architectural attributes, then lists any
condition-code effects and the concrete encoded forms allocated to that mnemonic.

In an encoding diagram, fixed 0 and 1 fields identify opcode bits. Lettered fields are decoded by the field notes
immediately below the diagram. An <ea> field is the compact effective-address field and may append EA payload bytes
in operand order.

Instruction entries are intentionally page-bounded: the next mnemonic starts on a new page so that a form diagram,
field explanation, and side-effect text are read as a single reference unit.
