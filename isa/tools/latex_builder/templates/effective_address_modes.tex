An effective-address field is an operand descriptor. It may select a register value, an immediate value, or a memory
operand pointer. Only memory forms continue into segment pre-translation and paging.

The seven-bit compact EA field is embedded in the opcode payload. Any displacement, absolute address, immediate, or
EXT0 descriptor bytes are appended as EA payload bytes. When an instruction contains multiple payload-bearing
operands, payloads are consumed in instruction operand order.

All EA payload bytes are little-endian. Payload names ending in s are signed and are sign-extended before use;
payload names without s are unsigned unless the consuming instruction explicitly says otherwise.

Indexed scale is implicit in the consuming instruction. For ordinary B/W/L/Q memory operations, the scale is 1, 2,
4, or 8. LEA uses its suffix to select the scale.

\clearpage
\subsection{Compact EA Addressing Modes}
Compact EA forms are the fast-path operand encodings. They cover direct Rn and SP operands, common Rn/SP/PC memory
operands, absolute memory operands, immediate operands, and the EXT0 escape.

Compact memory forms that do not name SP or PC use the operation default data segment. SP memory forms are fixed to
SS, and PC memory forms are fixed to CS.

\subsection{Extended EA Descriptor}
A compact EXT0 EA value selects an extended descriptor and the displacement width. The descriptor bytes then select
segment, base, index, zero-base, SP/PC indexed, and auto-update behavior.

EXT0 has no default segment as a descriptor class. A concrete descriptor either encodes SEG(s), selects fixed SS/CS
through SP or PC, or explicitly uses the operation default data segment.
