\subsection{Extended EA Addressing Modes}
EXT0 is used when compact EA cannot express the operand: explicit segment selection, indexed addressing, zero-base
addressing, SP/PC indexed addressing, or auto-update addressing.

EXT0 has no default segment as an encoding class. Each concrete form either encodes SEG(s), uses a fixed SP/PC
segment, or explicitly states that it uses the operation default data segment.
