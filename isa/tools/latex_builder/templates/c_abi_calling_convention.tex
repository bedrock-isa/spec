\subsection{Stack and Calls}
The stack grows @STACK_DIRECTION@. An architectural \texttt{CALL} pushes an
@RETURN_ADDRESS_SIZE@-byte return address at @RETURN_ADDRESS_LOCATION@, and
callers align \texttt{SP} before the call so callee entry observes
@STACK_ENTRY_ALIGNMENT@-byte alignment.

\subsection{Frame Pointer}
Frame pointers are @FRAME_POINTER_DEFAULT@.  When a function elects to keep a
frame pointer, it uses @FRAME_POINTER_REGISTER@.  @FRAME_POINTER_NOTE@
