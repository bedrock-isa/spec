\subsection{Register Model}\label{section:register-model}
The (:term:base.terms.general_purpose_register:) set contains sixteen 64-bit registers, R0 through R15. Instruction encodings use these
registers for integer values, addresses, counters, selectors, and temporary data.

SP and PC are special architectural registers outside the four-bit Rn namespace. SP-relative memory forms use SS by
default; PC-relative memory forms use CS by default.

CS, DS, SS, and GS0 through GS5 are 64-bit architectural segment registers. Segment-qualified EA forms select them
explicitly, while SP and PC forms omit the segment (:term:base.terms.field:) because their segment association is fixed.
