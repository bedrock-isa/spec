SAVE writes the fixed base block at the selected save-area address. It records the base header fields, the state-block bitmap, R0-R15, GS0--GS5 whose validity bits are set, FLAGS, and STATUS according to the Processor-State Save and Restore layout. It writes a format recognized by the current implementation. Enabled extension state blocks are written to their CPUID-defined component offsets; architecturally clean extension blocks may be skipped and reported clear in the state-block bitmap. Bitmap bits without a CPUID-described component are always clear.

The complete selected memory range is validated before architectural state is committed. Any access fault leaves the architectural register state and save area unchanged.
