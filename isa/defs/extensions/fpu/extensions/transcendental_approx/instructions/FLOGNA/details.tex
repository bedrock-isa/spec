\begin{manualflageffects}{FFLAGS}
\manualflageffect{NV}{may accrue}
\manualflageffect{DZ}{may accrue}
\manualflageffect{UF}{may accrue}
\end{manualflageffects}

The required FPTRANSA\_ACCURACY contract is \texttt{0x0041}. If PRESENT is clear, the instruction raises \texttt{ILLEGAL\_INSTRUCTION} before reading operands or floating-point state.

After FSTATUS.DAZ processing, the reference function is ln(x) on positive finite values and positive infinity after DAZ; signed zero is the DZ boundary. The result error is at most 4 ULP for S and 4 ULP for D.

\textbf{Special values}\par
\begin{itemize}
\item When the source is zero, DZ is accrued and the result is -infinity.
\item When the source \textless{} 0, NV is accrued and the result is the architectural default quiet NaN.
\item When the source is +infinity, the result is +infinity.
\item When the source equals 1, the result is positive zero.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item ln(+1) = +0
\item ln(signed 0) = -infinity
\item ln(+infinity) = +infinity
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item strictly increasing on the positive domain
\end{itemize}

A signaling NaN accrues NV. NaN results are quieted and then processed by FSTATUS.DN. FSTATUS.FTZ replaces a subnormal result with the required signed zero and accrues UF. OF and UF are accrued as specified by the common FPTRANSA model, while NX is unchanged.

If any accrued exception is enabled as a trap, the instruction raises \texttt{FLOATING\_POINT\_FAULT} before writing a destination; otherwise it commits the result and accrued flags together.
