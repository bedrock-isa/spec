\begin{manualflageffects}{FFLAGS}
\manualflageffect{NV}{may accrue}
\manualflageffect{OF}{may accrue}
\manualflageffect{UF}{may accrue}
\end{manualflageffects}

The required FPTRANSA\_ACCURACY contract is \texttt{0x0031}. If PRESENT is clear, the instruction raises \texttt{ILLEGAL\_INSTRUCTION} before reading operands or floating-point state.

After FSTATUS.DAZ processing, the reference function is e ** x on all finite values and signed infinity after DAZ. The result error is at most 4 ULP for S and 4 ULP for D.

\textbf{Special values}\par
\begin{itemize}
\item When the source is +infinity, the result is +infinity.
\item When the source is -infinity, the result is positive zero.
\item When the source is zero, the result is positive one.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item e ** signed 0 = +1
\item e ** +infinity = +infinity
\item e ** -infinity = +0
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item strictly increasing for finite inputs
\item result is nonnegative
\end{itemize}

A signaling NaN accrues NV. NaN results are quieted and then processed by FSTATUS.DN. FSTATUS.FTZ replaces a subnormal result with the required signed zero and accrues UF. OF and UF are accrued as specified by the common FPTRANSA model, while NX is unchanged.

If any accrued exception is enabled as a trap, the instruction raises \texttt{FLOATING\_POINT\_FAULT} before writing a destination; otherwise it commits the result and accrued flags together.
