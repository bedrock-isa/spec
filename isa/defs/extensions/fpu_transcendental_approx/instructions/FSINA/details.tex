The required FPTRANSA\_ACCURACY contract is \texttt{0x0000}. If PRESENT is clear, the instruction raises \texttt{ILLEGAL\_INSTRUCTION} before reading operands or floating-point state.

After FSTATUS.DAZ processing, the reference function is sin(x) in radians on finite x with abs(x) \textless{}= pi / 4 after DAZ. The result error is at most 4 ULP for S and 4 ULP for D.

\textbf{Special values}\par
\begin{itemize}
\item When the source is infinite or abs(the source) \textgreater{} pi / 4, NV is accrued and the result is the architectural default quiet NaN.
\item When the source is zero, the result is the source.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item sin(+0) = +0
\item sin(-0) = -0
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item odd
\item monotonically increasing on the contract domain
\item result is in [-sqrt(2)/2, sqrt(2)/2]
\end{itemize}

A signaling NaN accrues NV. NaN results are quieted and then processed by FSTATUS.DN. FSTATUS.FTZ replaces a subnormal result with the required signed zero and accrues UF. OF and UF are accrued as specified by the common FPTRANSA model, while NX is unchanged.

If any accrued exception is enabled as a trap, the instruction raises \texttt{FLOATING\_POINT\_FAULT} before writing a destination; otherwise it commits the result and accrued flags together.
