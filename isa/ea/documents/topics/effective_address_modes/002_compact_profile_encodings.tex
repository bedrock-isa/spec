\subsection{Compact Profile Encodings}
The scalar EA profile encodes common Rn/SP/PC memory operands, absolute memory operands, integer immediate operands,
and the EXT1 and EXT2 escapes. An extension-defined profile inherits only the forms explicitly stated by that
extension; an unassigned selector does not implicitly inherit the scalar EA form at the same value.

Compact memory forms that do not name SP or PC use the operation default data segment. SP memory forms are fixed to
SS, and PC memory forms are fixed to CS.
