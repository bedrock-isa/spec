\subsection{Trigger State and Retry}
Reset disables every slot and resets DTRSEL. Event entry does not modify the array. The array is per-processor debug
state rather than computational context and is not part of the normal SAVE/RESTORE image. STATUS.TF and STATUS.RF
remain execution-context state. RF suppression, automatic saved-image RF for pre-effect hardware events, and event
priority are specified in \hyperref[section:event-priority-and-debug]{Event Priority and Debug Stops}.
