Raise the explicit synchronous SYSTEM\_CALL event (\texttt{0x00000003}), saving the following instruction as UPC and entering the common EPC/ECS/EDS event handler on SSS:SSP without a memory frame.

Execution is valid only in user mode with no active architectural event. It selects the explicit synchronous (:ref:base.events.EXCEPTION.SYSTEM_CALL:) event, whose event code is \texttt{0x00000003}, priority is 4, frame class is BASIC, and saved PC is the following instruction.

On successful entry the common event mechanism atomically saves the user (:term:base.terms.continuation:) in UPC, USP, UCS, UDS, USS, UCTL, and UINFO; loads CS, DS, and PC from ECS, EDS, and EPC; selects SSS:SSP; and sets (:ref:base.registers.STATE.STATUS.PM:), (:ref:base.registers.STATE.STATUS.EA:), (:ref:base.registers.STATE.STATUS.EDEPTH:)\texttt{=1}, and (:ref:base.registers.STATE.STATUS.UO:). Because (:ref:base.events.EXCEPTION.SYSTEM_CALL:) has no (:term:base.terms.payload:), entry performs no stack-memory access. Return uses ERET. Software restarts the one-byte instruction by subtracting one from UPC before ERET.
