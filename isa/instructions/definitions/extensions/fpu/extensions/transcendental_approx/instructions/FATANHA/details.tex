The required FPTRANSA\_ACCURACY contract is \texttt{0x0024}.

\textbf{Special values}\par
\begin{itemize}
\item Zero source: the result is the source.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item atanh(+0) = +0
\item atanh(-0) = -0
\item atanh(signed 1) = signed infinity
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item odd
\item monotonically increasing on (-1, 1)
\end{itemize}
