The required FPTRANSA\_ACCURACY contract is \texttt{0x0033}. If that accuracy contract's \texttt{PRESENT} field is clear, the instruction raises \texttt{ILLEGAL\_INSTRUCTION} before reading operands or floating-point state.

After FSTATUS.DAZ processing, the reference function is 2 ** x on all finite values and signed infinity. The result error is at most 4 ULP for S and 4 ULP for D.

\textbf{Special values}\par
\begin{itemize}
\item When the source is +infinity, the result is +infinity.
\item When the source is -infinity, the result is positive zero.
\item When the source is zero, the result is positive one.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item 2 ** signed 0 = +1
\item 2 ** +infinity = +infinity
\item 2 ** -infinity = +0
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item strictly increasing for finite inputs
\item result is nonnegative
\end{itemize}

NaN, exception, trap, and commit handling follows the common FPTRANSA model in Section~\ref{section:fptransa-common-model}.
