The required FPTRANSA\_ACCURACY contract is \texttt{0x0042}.

\textbf{Special values}\par
\begin{itemize}
\item Source equal to -1: DZ is generated and the result is -infinity.
\item Source below -1: NV is generated and the result is the architectural default quiet NaN.
\item Positive infinity: the result is +infinity.
\item Zero source: the result is the source.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item log1p(+0) = +0
\item log1p(-0) = -0
\item log1p(-1) = -infinity
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item strictly increasing on (-1, +infinity)
\end{itemize}
