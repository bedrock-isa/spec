The required FPTRANSA\_ACCURACY contract is \texttt{0x0022}.

\textbf{Special values}\par
\begin{itemize}
\item Infinite source: the result is +infinity.
\item Zero source: the result is positive one.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item cosh(+0) = +1
\item cosh(-0) = +1
\item cosh(infinity) = +infinity
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item even
\item nonincreasing below zero and nondecreasing above zero
\item result is at least 1
\end{itemize}
