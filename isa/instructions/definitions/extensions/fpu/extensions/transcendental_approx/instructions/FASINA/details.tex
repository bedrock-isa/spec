The required FPTRANSA\_ACCURACY contract is \texttt{0x0011}. If that accuracy contract's \texttt{PRESENT} field is clear, the instruction raises \texttt{ILLEGAL\_INSTRUCTION} before reading operands or floating-point state.

After FSTATUS.DAZ processing, the reference function is asin(x) in radians on finite x with abs(x) \textless{}= 1. The result error is at most 4 ULP for S and 4 ULP for D.

\textbf{Special values}\par
\begin{itemize}
\item When the source is zero, the result is the source.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item asin(+0) = +0
\item asin(-0) = -0
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item odd
\item monotonically increasing on [-1, 1]
\item result is in [-pi/2, pi/2]
\end{itemize}

NaN handling, floating-point exception-cause generation, matching condition-enable testing, \texttt{FLOATING\_POINT\_FAULT} architectural-event delivery, and commit behavior follow the common FPTRANSA model in Section~\ref{section:fptransa-common-model}.
