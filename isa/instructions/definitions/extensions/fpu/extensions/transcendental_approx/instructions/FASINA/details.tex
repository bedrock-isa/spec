The required FPTRANSA\_ACCURACY contract is \texttt{0x0011}.

\textbf{Special values}\par
\begin{itemize}
\item Zero source: the result is the source.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item asin(+0) = +0
\item asin(-0) = -0
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item odd
\item monotonically increasing on [-1, 1]
\item result is in [-pi/2, pi/2]
\end{itemize}
