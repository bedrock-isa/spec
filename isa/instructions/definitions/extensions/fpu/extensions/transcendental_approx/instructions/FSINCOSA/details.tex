The required FPTRANSA\_ACCURACY contract is \texttt{0x0004}. If that accuracy contract's \texttt{PRESENT} field is clear, the instruction raises \texttt{ILLEGAL\_INSTRUCTION} before reading operands or floating-point state.

After FSTATUS.DAZ processing, the reference function is paired sin(x) and cos(x) in radians on finite x with abs(x) \textless{}= pi / 4. The result error is at most 4 ULP for S and 4 ULP for D.

\textbf{Special values}\par
\begin{itemize}
\item When the two destinations name the same F register, \texttt{ILLEGAL\_INSTRUCTION} is raised before operands or floating-point state are read.
\item When the source is infinite or its magnitude exceeds pi / 4, NV is generated and both results are the architectural default quiet NaN.
\item When the source is zero, the sine result preserves the source zero and the cosine result is positive one.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item sin(+0) = +0 and cos(+0) = +1
\item sin(-0) = -0 and cos(-0) = +1
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item the ULP bound applies independently to both results
\item results need not match separate FSINA and FCOSA executions
\end{itemize}

For nontrapping execution, the sine and cosine destinations are written atomically.

NaN handling, floating-point exception-cause generation, matching condition-enable testing, \texttt{FLOATING\_POINT\_FAULT} architectural-event delivery, and commit behavior follow the common FPTRANSA model in Section~\ref{section:fptransa-common-model}.
