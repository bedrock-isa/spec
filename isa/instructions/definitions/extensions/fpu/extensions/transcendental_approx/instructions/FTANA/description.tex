Computes the tan(x) reference in radians over finite x with abs(x) \textless{}= pi / 4 after DAZ and writes an implementation-bounded S- or D-format approximation under the selected FPTRANSA accuracy contract.

The required FPTRANSA\_ACCURACY contract is \texttt{0x0003}.

\textbf{Special values}\par
\begin{itemize}
\item Infinite source or source magnitude above pi / 4: NV is generated and the result is the architectural default quiet NaN.
\item Zero source: the result is the source.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item tan(+0) = +0
\item tan(-0) = -0
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item odd
\item monotonically increasing on the contract domain
\item result is in [-1, 1]
\end{itemize}
