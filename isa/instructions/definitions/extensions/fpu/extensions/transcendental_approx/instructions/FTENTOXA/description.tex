Computes the 10 ** x reference over all finite values and signed infinity after DAZ and writes an implementation-bounded S- or D-format approximation under the selected FPTRANSA accuracy contract.

The required FPTRANSA\_ACCURACY contract is \texttt{0x0034}. If that accuracy contract's \texttt{PRESENT} field is clear, the instruction raises \texttt{ILLEGAL\_INSTRUCTION} before reading operands or floating-point state.

After FSTATUS.DAZ processing, the reference function is 10 ** x on all finite values and signed infinity. The result error is at most 4 ULP for S and 4 ULP for D.

\textbf{Special values}\par
\begin{itemize}
\item When the source is +infinity, the result is +infinity.
\item When the source is -infinity, the result is positive zero.
\item When the source is zero, the result is positive one.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item 10 ** signed 0 = +1
\item 10 ** +infinity = +infinity
\item 10 ** -infinity = +0
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item strictly increasing for finite inputs
\item result is nonnegative
\end{itemize}

NaN handling, floating-point exception-cause generation, matching condition-enable testing, \texttt{FLOATING\_POINT\_FAULT} architectural-event delivery, and commit behavior follow the common FPTRANSA model in Section~\ref{section:fptransa-common-model}.
