The required FPTRANSA\_ACCURACY contract is \texttt{0x0032}.

\textbf{Special values}\par
\begin{itemize}
\item Positive infinity: the result is +infinity.
\item Negative infinity: the result is -1.
\item Zero source: the result is the source.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item expm1(+0) = +0
\item expm1(-0) = -0
\item expm1(-infinity) = -1
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item strictly increasing for finite inputs
\item result is at least -1
\end{itemize}
