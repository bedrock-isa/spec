Each active H or S source value is converted to D. The signed-integer forms
convert each active L or Q source value to D. The operation uses 64-bit
containers, reads the source from the low source-width field, and writes the D
result to the complete container. Every inactive container retains its
previous value.

A completed conversion accrues generated NV, OF, UF, and NX causes in FFLAGS;
DZ is unchanged. An enabled generated cause raises FLOATING\_POINT\_FAULT and
suppresses destination and newly accrued FFLAGS effects.
