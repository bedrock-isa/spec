Classify the return source before stack access, then atomically return through a valid staged or outer-event U bank, or restore a valid active supervisor event frame.

{\raggedright
\begin{enumerate}
\item Classify the return source before any stack access. A staged direct user entry requires supervisor mode, (:ref:base.registers.STATE.STATUS.EA:) clear, (:ref:base.registers.STATE.STATUS.EDEPTH:) zero, (:ref:base.registers.STATE.STATUS.UO:) clear, and (:ref:base.control_registers.UCTL.V:) set. An outer user-event return requires (:ref:base.registers.STATE.STATUS.EA:) set, (:ref:base.registers.STATE.STATUS.EDEPTH:) one, (:ref:base.registers.STATE.STATUS.UO:) set, and (:ref:base.control_registers.UCTL.V:) set. Other active supervisor returns use the memory frame.
\item For a U-bank return, validate UCTL, UINFO, the user segments and pointers, and the executable UPC, then atomically restore user state, clear (:ref:base.control_registers.UCTL.V:), (:ref:base.registers.STATE.STATUS.EDEPTH:), (:ref:base.registers.STATE.STATUS.UO:), (:ref:base.registers.STATE.STATUS.EA:), and current DFA, and perform no stack access.
\item For a stacked return, read and decode (:ref:base.events.frame.EVENT_FRAME.FRAME_CONTROL:) at SS:SP without changing SP. Accept only the
defined BASIC, ERROR, PAGE, and AUXILIARY sizes, with all (:term:base.terms.reserved:) bits zero.
\item Validate that saved (:ref:base.registers.STATE.STATUS.EDEPTH:) plus one equals the current depth and that saved and current (:ref:base.registers.STATE.STATUS.UO:) preserve the outer-origin chain.
\item Read the complete selected frame and validate (:ref:base.events.frame.EVENT_FRAME.FRAME_CONTROL.FLAGS:), (:ref:base.events.frame.EVENT_FRAME.FRAME_CONTROL.STATUS:), CS, DS, SS, SP, and an executable canonical PC without changing (:term:base.terms.architectural_state:).
\item Ignore the value in the fixed-header (:ref:base.events.frame.EVENT_FRAME.PADDING:) slot at offset +0x38.
\item Atomically restore the validated (:term:base.terms.architectural_state:) and current DFA from
(:ref:base.events.frame.EVENT_FRAME.FRAME_CONTROL.SAVED_DFA:). Hidden repeat state remains clear;
if (:ref:base.events.frame.EVENT_FRAME.SAVED_PC:) identifies a repeat prefix, that prefix is decoded and executed normally after return.
\item After restoration, admit a pending NMI before the next instruction boundary when (:ref:base.registers.STATE.STATUS.NI:) is clear and (:ref:base.control_registers.ECR.NMI_P:) is set.
\end{enumerate}
\par}
