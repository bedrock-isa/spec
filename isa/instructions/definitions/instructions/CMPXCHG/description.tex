Compares memory with the expected Rn register and conditionally stores the desired Rn register. After the operation, the expected register contains the observed old memory value. Z=1 means the store happened; Z=0 means memory was left unchanged.

The memory read, optional memory write, expected-register update, and flag update form one atomic read-modify-write operation.
The encoded memory-order selector governs the complete operation on both comparison outcomes. On failure, the
operation contributes the observed memory read as its ordering event: acquire orders later memory operations after
that read, release orders earlier memory operations before that read, and sequential consistency places that read in
the global SC order. On success, the memory write carries the same selected order to observers of that write. A
failed comparison contributes no memory write and creates no release sequence.

\begin{itemize}
\item If memory equals the original expected value, the desired value is stored and Z is set.
\item Otherwise memory is unchanged and Z is cleared.
\item In both cases the expected register receives the value originally read from memory, and N, C, and V are cleared.
\end{itemize}
A memory-access fault exposes none of these updates.
