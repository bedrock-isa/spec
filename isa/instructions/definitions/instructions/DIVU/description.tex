Divides the selected-width unsigned destination value by the unsigned source value and writes the quotient. A zero divisor raises DIVIDE\_ERROR.

Let \(n\) be the selected operand width, \(d\) the unsigned dividend, and \(s\) the unsigned divisor. The quotient and remainder are defined by
\[
  q = \lfloor d/s \rfloor,
  \qquad r = d - qs .
\]
For a nonzero divisor, the remainder satisfies \(0 \le r < s\). The destination supplies the dividend and receives \(q\).

A zero divisor raises \texttt{DIVIDE\_ERROR}; no destination is changed.
