WRSEG validates a 64-bit (:term:base.terms.segment_register_image:) from the source (:term:base.terms.rn_register:) and writes it to the selected SREG.

The complete source image is validated before (:term:base.terms.architectural_state:) changes. An invalid image raises
(:ref:base.events.EXCEPTION.INVALID_CONTROL_IMAGE:); the selected segment register remains unchanged when validation fails.
