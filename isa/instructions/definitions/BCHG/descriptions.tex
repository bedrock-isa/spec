Complements the destination bit selected by the low six bits of the bit index, writes (:ref:base.registers.STATE.FLAGS.Z:) from whether that bit was previously clear, and clears (:ref:base.registers.STATE.FLAGS.N:), (:ref:base.registers.STATE.FLAGS.C:), and (:ref:base.registers.STATE.FLAGS.V:). A memory destination is read by an (:term:base.terms.ordinary:) selected-width load and updated by an (:term:base.terms.ordinary:) selected-width store. The B-sized 0 or 1 value of the old tested bit supplies the REPcc observed value.
