With paging disabled, VTOP returns the supplied address when it fits (:ref:base.cpuid.IMPLEMENTATION.ADDRESS_WIDTHS.PARAMETERS.PABITS:). With paging enabled, it returns the current physical byte-address translation without accessing the translated target. (:ref:base.registers.STATE.FLAGS.Z:) reports success; (:ref:base.registers.STATE.FLAGS.N:), (:ref:base.registers.STATE.FLAGS.C:), and (:ref:base.registers.STATE.FLAGS.V:) are zero. The query does not modify (:ref:base.memory.translation.PTE.A:) or (:ref:base.memory.translation.PTE.D:).

The source address is checked for canonicality before the page-table walk. The walk begins at the PTCR root and follows the active LA48 or LA57 hierarchy using the virtual page number.

Every continuing entry must be a valid table pointer. (:ref:base.memory.translation.PTE.R:), (:ref:base.memory.translation.PTE.W:), (:ref:base.memory.translation.PTE.X:), and (:ref:base.memory.translation.PTE.U:) are intersected across table pointers and the terminating leaf (:ref:base.memory.translation.PTE.AM:). A valid leaf at level $L$ combines its naturally aligned physical base with the original low $12+9(L-1)$ address bits to form a byte address. Success sets (:ref:base.registers.STATE.FLAGS.Z:) and clears (:ref:base.registers.STATE.FLAGS.N:), (:ref:base.registers.STATE.FLAGS.C:), and (:ref:base.registers.STATE.FLAGS.V:). Any canonicality, (:ref:base.cpuid.IMPLEMENTATION.ADDRESS_WIDTHS.PARAMETERS.PABITS:), or walk failure returns zero and clears all four flags without raising an access exception, setting (:ref:base.memory.translation.PTE.A:) or (:ref:base.memory.translation.PTE.D:), or modifying the TLB.
