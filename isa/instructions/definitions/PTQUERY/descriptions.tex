PTQUERY reads the raw descriptor selected by a (:term:base.terms.linear_address:) and requested page-table level, or returns zero when the requested entry cannot be read. (:ref:base.registers.STATE.FLAGS.Z:) reports structural validity under the layout selected by (:ref:base.memory.translation.PTE.T:); (:ref:base.registers.STATE.FLAGS.N:), (:ref:base.registers.STATE.FLAGS.C:), and (:ref:base.registers.STATE.FLAGS.V:) are zero.

The requested level is the low three bits of the level operand. Values outside 1 through 4 raise (:ref:base.events.EXCEPTION.INVALID_CONTROL_SELECTOR:).
With (:ref:base.control_registers.PTCR.TT:)\texttt{=010}, an L4 query is reported as an (:term:base.terms.ordinary:) unsuccessful query before reading a PTE.
With an unallocated (:ref:base.control_registers.PTCR.TT:) encoding, no geometry is selected and every query is reported as an (:term:base.terms.ordinary:)
unsuccessful query before reading a PTE.

\begin{enumerate}
\item Compute the (:term:base.terms.linear_address:) without reading the source memory and reject a noncanonical address as an unsuccessful query.
\item Starting at the PTCR root, read one 64-bit PTE per level. Every preceding entry must be a valid table pointer; a valid earlier leaf prevents traversal to a lower requested level.
\item Stop after reading the requested level. A structurally malformed entry or valid leaf terminates the query at that level.
\item Return the requested raw PTE and set (:ref:base.registers.STATE.FLAGS.Z:) only when it is structurally valid under the table-pointer or leaf layout selected by (:ref:base.memory.translation.PTE.T:) at that level. (:ref:base.registers.STATE.FLAGS.N:), (:ref:base.registers.STATE.FLAGS.C:), and (:ref:base.registers.STATE.FLAGS.V:) are zero.
\end{enumerate}
Failure before the requested entry is read returns zero and clears all four flags. The walk ignores (:ref:base.control_registers.PTCR.PE:), does not set (:ref:base.memory.translation.PTE.A:) or (:ref:base.memory.translation.PTE.D:), does not modify a TLB, and does not raise an \texttt{ADDRESS\_TRANSLATION} family event for walk failure.
