SETF replaces the complete architectural integer FLAGS image from its encoded bitmap. Bit 3 writes (:ref:base.registers.STATE.FLAGS.Z:), bit 2 writes (:ref:base.registers.STATE.FLAGS.N:), bit 1 writes (:ref:base.registers.STATE.FLAGS.C:), and bit 0 writes (:ref:base.registers.STATE.FLAGS.V:); a one writes the corresponding flag to one and a zero writes it to zero. The assembler may provide symbolic bitmap names such as \texttt{Z}, \texttt{N}, \texttt{C}, \texttt{V}, and combinations using \textbar{}.
