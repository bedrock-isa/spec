\subsection{Debug-Trigger Discovery}
The mandatory Base trigger array has at least four slots per (:term:base.terms.logical_processor:).
(:ref:base.cpuid.IMPLEMENTATION.DEBUG_TRIGGERS.PARAMETERS.SLOT_COUNT:) reports the exact number accepted by (:ref:base.control_registers.DTRSEL.SLOT:); software does not probe selector values
beyond that count.
