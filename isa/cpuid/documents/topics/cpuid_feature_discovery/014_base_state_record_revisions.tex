\subsection{Base State-Record Revisions}

The BASE\_STATE\_RECORDS leaf reports independent 8-bit format revisions for the base user and base supervisor records. Revision 1 identifies the fixed layouts defined by this specification. A revision value of zero means the corresponding record format is unavailable.

Record sizes and alignments are architectural properties of the reported revision and are not repeated in CPUID.
