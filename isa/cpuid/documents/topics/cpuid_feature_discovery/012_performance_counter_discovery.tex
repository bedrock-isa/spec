\subsection{Performance-Counter Discovery}\label{section:performance-counter-discovery}
Class \texttt{0x00000002}, leaf \texttt{0x0002} uses indexes 1 through 65535 as RDPMC counter IDs. Index zero is the
common (:term:base.terms.header:). Result bit 0 is \texttt{PRESENT}; bits 63..1 are (:term:base.terms.reserved:) and read as zero. CYCLE, INSTRET, and PTWALK
IDs 1, 2, and 3 are mandatory and therefore always report present; the index-zero (:term:base.terms.header:) reports
\texttt{MAX\_INDEX=3} when no implementation-defined counter has a greater ID. An implementation-defined ID may be
used only when its query reports present.
