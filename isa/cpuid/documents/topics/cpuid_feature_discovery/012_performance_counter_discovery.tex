\subsection{Performance-Counter Discovery}\label{section:performance-counter-discovery}
This leaf determines whether an RDPMC counter ID is available on the current (:term:base.terms.logical_processor:).
Counter IDs form a sparse space: the (:term:base.terms.header:) bounds the selectors that software may examine but does
not imply that every intervening ID is present. Software checks the selected ID before issuing RDPMC.

The standard counter events are defined by (:ref:base.instructions.RDPMC:). An implementation-defined counter
additionally requires implementation documentation that names the event counted by its ID.
