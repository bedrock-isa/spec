\section{Scope and Status}
This guide is non-normative. It illustrates possible C-library, compiler, and
runtime uses of Bedrock instructions; it does not define architectural
behavior, an ABI contract, a compiler interface, or a required implementation
strategy.

Normative instruction behavior is defined by the Bedrock ISA Specification.
Calling convention, pointer layout, and C atomic lowering are defined by the
Bedrock C ABI. ELF symbols, relocations, dynamic linking, and TLS loader
contracts are defined by the Bedrock ELF ABI. Compiler modes, builtins, and
lowering interfaces are defined by the applicable compiler and Target
Intrinsics documents.
