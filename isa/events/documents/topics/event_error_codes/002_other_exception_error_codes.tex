\subsubsection{Other Exception Payloads}
Integer-divide, instruction-validation, control-state, privilege, debug, and vector-range failures are independently
allocated leaf events. Their event code identifies the precise condition, so these events use BASIC frames and do not
repeat a cause number in ERROR\_CODE.

The (:ref:FP.events.EXCEPTION.FLOATING_POINT_EXCEPTION:) event uses an ERROR frame because one operation may raise several enabled
floating-point conditions together. ERROR\_CODE[4:0] is a bitmap: bits 4 through 0 are \texttt{NV}, \texttt{DZ},
\texttt{OF}, \texttt{UF}, and \texttt{NX}; bits 63 through 5 are zero.

\texttt{I}, \texttt{Z}, \texttt{O}, \texttt{U}, and \texttt{X} abbreviate \texttt{NV}, \texttt{DZ},
\texttt{OF}, \texttt{UF}, and \texttt{NX}.
\par}

The bounds instructions report comparison failure through \texttt{FLAGS.V}. Segment bounds failures raise
(:ref:base.events.EXCEPTION.SEGMENT_BOUNDS_VIOLATION:). (:ref:base.instructions.BKPT:) raises (:ref:base.events.EXCEPTION.BREAKPOINT:); (:ref:base.events.EXCEPTION.DEBUG_TRACE:) is generated
by the architectural trace mechanism.
