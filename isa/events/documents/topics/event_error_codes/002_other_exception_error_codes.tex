\subsubsection{Other Exception Payloads}
Integer-divide, instruction-validation, control-state, privilege, and debug failures are independently
allocated leaf events. Their event code identifies the precise condition, so these events use BASIC frames and do not
repeat a cause number in ERROR\_CODE.

The bounds instructions report comparison failure through \texttt{FLAGS.V}. Segment bounds failures raise
(:ref:base.events.EXCEPTION.SEGMENT_BOUNDS_VIOLATION:). (:ref:base.instructions.BKPT:) raises
(:ref:base.events.EXCEPTION.BREAKPOINT:); (:ref:base.events.EXCEPTION.DEBUG_TRACE:) is generated by the architectural
trace mechanism.
