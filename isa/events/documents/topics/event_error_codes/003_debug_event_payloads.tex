\subsubsection{Debug Event Payloads}
(:ref:base.events.EXCEPTION.SINGLE_STEP:) and
(:ref:base.events.EXCEPTION.EXPLICIT_BREAKPOINT:) use BASIC frames and carry no address payload.
(:ref:base.events.EXCEPTION.EXECUTION_BREAKPOINT:) uses an ERROR frame; ERROR\_CODE bits 15 through 0 contain the
zero-based winning trigger-slot number and all other bits are zero. Its saved PC is the matched address.

The three memory-watchpoint events use PAGE frames. FAULT\_EA contains the matched pre-segment effective address and
FAULT\_LINEAR contains its segment-pretranslated linear address. ERROR\_CODE has the following event-specific format.
