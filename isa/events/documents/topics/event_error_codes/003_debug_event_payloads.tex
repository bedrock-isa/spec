\subsubsection{Debug Event Payloads}
(:ref:base.events.EXCEPTION.SINGLE_STEP:) and
(:ref:base.events.EXCEPTION.EXPLICIT_BREAKPOINT:) use BASIC frames and carry no address payload.
(:ref:base.events.EXCEPTION.EXECUTION_BREAKPOINT:) uses an ERROR frame; (:ref:base.events.frame.EVENT_FRAME.ERROR_CODE:) bits 15 through 0 contain the
(:event-structure-target:base.events.payloads.EXECUTION_BREAKPOINT_ERROR_CODE.TRIGGER_SLOT:)\texttt{TRIGGER\_SLOT} number and all other bits are zero. Its saved PC is the matched address.

The three memory-watchpoint events use PAGE frames. (:ref:base.events.frame.EVENT_FRAME.FAULT_EA:) contains the matched pre-segment effective address and
(:ref:base.events.frame.EVENT_FRAME.FAULT_LINEAR:) contains its segment-pretranslated linear address. (:ref:base.events.frame.EVENT_FRAME.ERROR_CODE:) has the following event-specific format.
