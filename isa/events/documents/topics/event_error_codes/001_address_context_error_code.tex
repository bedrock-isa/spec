\subsubsection{Address-Context Payload}
Events in the \texttt{ADDRESS\_TRANSLATION} and \texttt{PHYSICAL\_ACCESS} families use the PAGE frame. The leaf
event code identifies the failure; (:ref:base.events.frame.EVENT_FRAME.ERROR_CODE:) carries only the access context common to those events.

Saved (:ref:base.registers.STATE.STATUS.PM:) records the originating privilege. (:ref:base.events.payloads.PAGE_ERROR_CODE.USER_DOMAIN:) distinguishes the (:term:base.terms.ordinary:) user
permission path from the checked user-access path used by supervisor instructions such as (:ref:base.instructions.MOVUC:),
(:ref:base.instructions.MOVCU:), and (:ref:base.instructions.MOVUU:). An atomic read-modify-write reports (:ref:base.events.payloads.PAGE_ERROR_CODE.ACCESS:)\texttt{=write}. Events detected
during a page-table walk report the applicable level; events detected before a walk and every event in the
\texttt{PHYSICAL\_ACCESS} family report level zero.

(:ref:base.events.payloads.PAGE_ERROR_CODE.ACCESS_SIZE:) records the architectural transfer width when one of the B, W, L, or Q widths applies. It is
zero when no such width is available or applicable. (:ref:base.events.frame.EVENT_FRAME.FAULT_EA:) is the numeric (:term:base.terms.effective_address:) before
(:term:base.terms.segment_pre_translation:). (:ref:base.events.frame.EVENT_FRAME.FAULT_LINEAR:) is the result after (:term:base.terms.segment_pre_translation:). A value not produced is
zero and has its corresponding validity bit clear.
