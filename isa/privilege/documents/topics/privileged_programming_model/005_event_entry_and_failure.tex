\subsection{Event Entry and Failure}
User-origin entry atomically saves the user context bank, optionally stores the (:term:base.terms.payload:), loads EPC/ECS/EDS and the selected initial stack, sets (:ref:base.registers.STATE.STATUS.PM:) and (:ref:base.registers.STATE.STATUS.EA:), sets (:ref:base.registers.STATE.STATUS.EDEPTH:) to one and (:ref:base.registers.STATE.STATUS.UO:) to one, and clears (:ref:base.registers.STATE.STATUS.IE:), (:ref:base.registers.STATE.STATUS.TF:), and (:ref:base.registers.STATE.STATUS.RF:). Supervisor and nested entry save the prior context in the full frame and increment (:ref:base.registers.STATE.STATUS.EDEPTH:) while preserving (:ref:base.registers.STATE.STATUS.UO:).

Delivery failure selects DSS:DSP and attempts the corresponding \texttt{EVENT\_DELIVERY\_FAILURE} leaf event. The hidden current-DFA bit is set when that entry commits. Failure while current DFA is set, or failure of that delivery attempt, enters shutdown. A full frame saves the prior DFA state in (:ref:base.events.frame.EVENT_FRAME.FRAME_CONTROL.SAVED_DFA:).
