\subsection{Privilege and Event State}
(:ref:base.registers.STATE.STATUS.PM:) is zero in user mode and one in supervisor mode. (:ref:base.registers.STATE.STATUS.EA:) indicates active event processing. (:ref:base.registers.STATE.STATUS.EDEPTH:) in bits 9..6 is the active event depth, and (:ref:base.registers.STATE.STATUS.UO:) in bit 10 records that the outer event originated in user mode. (:ref:base.registers.STATE.STATUS.PM:), (:ref:base.registers.STATE.STATUS.EA:), (:ref:base.registers.STATE.STATUS.EDEPTH:), and (:ref:base.registers.STATE.STATUS.UO:) are hardware managed; WRSTATUS must preserve them. User execution always observes (:ref:base.registers.STATE.STATUS.PM:)\texttt{=}(:ref:base.registers.STATE.STATUS.EA:)\texttt{=}(:ref:base.registers.STATE.STATUS.EDEPTH:)\texttt{=}(:ref:base.registers.STATE.STATUS.UO:)\texttt{=0}.

(:ref:base.registers.STATE.STATUS.IE:) enables maskable interrupts, (:ref:base.registers.STATE.STATUS.TF:) requests single-step tracing, (:ref:base.registers.STATE.STATUS.RF:) suppresses one trace boundary, and (:ref:base.registers.STATE.STATUS.NI:) inhibits nested NMI admission. RDCR, WRCR, translation-state changes, event-control changes, and page-table context switches require supervisor privilege unless an instruction explicitly states otherwise.
