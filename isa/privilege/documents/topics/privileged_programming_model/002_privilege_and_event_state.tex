\subsection{Privilege and Event State}
(:ref:base.registers.STATE.STATUS.PM:) is zero in user mode and one in supervisor mode. (:ref:base.registers.STATE.STATUS.EA:) indicates active event processing. (:ref:base.registers.STATE.STATUS.EDEPTH:) in bits 9..6 is the active event depth, and (:ref:base.registers.STATE.STATUS.UO:) in bit 10 records that the outer event originated in user mode. PM, EA, EDEPTH, and UO are hardware managed; WRSTATUS must preserve them. User execution always observes PM=EA=EDEPTH=UO=0.

IE enables maskable interrupts, TF requests single-step tracing, RF suppresses one trace boundary, and NI inhibits nested NMI admission. RDCR, WRCR, translation-state changes, event-control changes, and page-table context switches require supervisor privilege unless an instruction explicitly states otherwise.
