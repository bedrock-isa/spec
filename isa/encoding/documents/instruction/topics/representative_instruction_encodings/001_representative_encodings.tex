\subsection{Representative Encodings}

The following (:term:base.terms.opcode_space:) byte layouts show framing, encoded length, fixed (:term:base.terms.opcode:) bits, and
operand-selector (:term:base.terms.field|plural:) in instruction-stream order. Each row is read from bit 7 to bit 0.

\begin{BedrockListedBitDiagram}{Short Encoding for MOV.X(z:L/Q) Rn(s), Rn(d)}
\BedrockBitFieldRow{byte 0}{\BedrockByteRowLabels{0}{1}}{%
\BedrockBitFixed{10}{2}
\BedrockBitFixed{00000}{5}
\BedrockBitFieldText{z}{1}
}
\BedrockBitFieldRow{byte 1}{\BedrockByteRowLabels{1}{1}}{%
\BedrockBitFieldText{s}{4}
\BedrockBitFieldText{d}{4}
}
\end{BedrockListedBitDiagram}

\begin{BedrockListedBitDiagram}{Medium Encoding for MOV.X(z:B/W/L/Q) Rn(s), \textless{}ea\textgreater{}(e)}
\BedrockBitFieldRow{byte 0}{\BedrockByteRowLabels{0}{1}}{%
\BedrockBitFixed{11}{2}
\BedrockBitFixed{0000}{4}
\BedrockBitFixed{00}{2}
}
\BedrockBitFieldRow{byte 1}{\BedrockByteRowLabels{1}{1}}{%
\BedrockBitFixed{000}{3}
\BedrockBitFieldText{z}{2}
\BedrockBitFieldText{s}{3}
}
\BedrockBitFieldRow{byte 2}{\BedrockByteRowLabels{2}{1}}{%
\BedrockBitFieldText{s}{1}
\BedrockBitFieldText{e}{7}
}
\end{BedrockListedBitDiagram}

\begin{BedrockListedBitDiagram}{Long Encoding for ADC.X(z:B/W/L/Q) Rn(s), \textless{}ea\textgreater{}(e)}
\BedrockBitFieldRow{byte 0}{\BedrockByteRowLabels{0}{1}}{%
\BedrockBitFixed{11}{2}
\BedrockBitFixed{0001}{4}
\BedrockBitFixed{11}{2}
}
\BedrockBitFieldRow{byte 1}{\BedrockByteRowLabels{1}{1}}{%
\BedrockBitFixed{11001100}{8}
}
\BedrockBitFieldRow{byte 2}{\BedrockByteRowLabels{2}{1}}{%
\BedrockBitFieldText{z}{2}
\BedrockBitFixed{100}{3}
\BedrockBitFieldText{s}{3}
}
\BedrockBitFieldRow{byte 3}{\BedrockByteRowLabels{3}{1}}{%
\BedrockBitFieldText{s}{1}
\BedrockBitFieldText{e}{7}
}
\end{BedrockListedBitDiagram}

In these examples, \texttt{z} selects the operation size, \texttt{s} and \texttt{d} select integer registers,
and \texttt{e} selects an effective-address form. A (:term:base.terms.field:) may cross a byte boundary, as \texttt{s} does in the
medium and long examples.
