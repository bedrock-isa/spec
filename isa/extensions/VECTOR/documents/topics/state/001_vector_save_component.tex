\subsection{Vector SAVE Component}
When VECTOR is present, component ID 2 uses bitmap bit 1 and contains the complete V0 through V31 and packed P0
through P15 images. Let \(B\) be VLEN in bytes. The reported component size is
\(64\lceil 34B/64\rceil\), and its initial and reset state is all zero. A committed Vn or Pn write marks the component
modified.
