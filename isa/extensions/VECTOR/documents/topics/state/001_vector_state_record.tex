\subsection{Vector User-State Record}

(:memory-record:VECTOR.records.USER_STATE:)

Its initial state is zero in V0 through V31, P0 through P15, and VSTATUS.

For VRESTORE, a clear presence bit installs the selected image's initial value and its payload bytes are not read. All selected images and reserved header fields are validated before any vector state is committed. An all-clear bitmap makes vector state clean; any set bit makes it modified. VSAVE does not change this tracking state and may conservatively set presence bits.
