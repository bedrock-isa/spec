\subsection{Vector-Parameter Discovery}
Class \texttt{0x00000001}, leaf \texttt{0x0000}, index one, bit two is the \texttt{VECTOR} discovery predicate.
Class \texttt{0x00000001}, leaf \texttt{0x0002} is \texttt{VECTOR\_PARAMETERS}. Index zero reports
\texttt{MAX\_INDEX=1}. Index one returns \texttt{VLEN\_LOG2\_BITS} in bits 3 through 0 and zero in bits 63 through
4. The value is the base-2 logarithm of VLEN in bits and is in the range 7 through 11. Consequently VLEN is an
implementation-selected power of two from 128 through 2048 bits. The selected value is stable until reset.
