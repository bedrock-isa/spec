PUNPKLO reads the significant predicate positions for the selected B, W, or L
source element width.  It selects the lower half of those positions and copies
them in lane order to the significant destination positions for elements twice
that width.  The complete destination predicate image is written, and every bit
outside the significant destination positions is cleared.  The operation leaves FLAGS
unchanged.
