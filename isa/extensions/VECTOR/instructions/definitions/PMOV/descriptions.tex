PMOV transfers one complete current predicate execution image between
\texttt{Pn} and contiguous memory. The transfer contains the current VLEN/64
bytes. The memory-source form replaces the low VLEN/8 destination predicate
bits and preserves storage bits at or above VLEN/8; the memory-destination form
stores the low VLEN/8 source predicate bits. No
element predicate applies to either form.

The effective-address calculation, complete image transfer, and any
effective-address auto-update commit as one vector (:term:base.terms.memory_operation:).  A fault
commits none of those effects.  The operation leaves FLAGS unchanged.
