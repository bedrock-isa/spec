PZIPHI selects the upper half of the significant predicate lanes for the chosen B, W, L, or Q width from each source.
In increasing order through those halves, each even result lane receives a left-source value and the following odd result lane receives the corresponding right-source value.
The complete destination predicate image is written, and every nonsignificant bit is cleared.
The operation leaves FLAGS unchanged.
