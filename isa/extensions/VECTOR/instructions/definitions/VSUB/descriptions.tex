VSUB subtracts each corresponding active source element from its destination
element. For B, W, L, and Q elements, the selected-width modular difference
replaces the destination element. The register form and the memory-source form
write the result to the destination vector lane. An inactive destination lane
retains its previous value.

The memory-destination form reads each active destination element, subtracts
the corresponding source-register element, and writes the result back to that
memory element. Inactive memory elements retain their previous values, making
the destination transaction a lane-wise read-modify-write.
