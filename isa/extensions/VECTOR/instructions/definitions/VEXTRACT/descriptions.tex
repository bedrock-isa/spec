VEXTRACT interprets the scalar index as unsigned and selects that lane from
Vn. The B, W, L, and Q forms zero-extend the selected lane to the complete Rn
result.

An index at or above the selected vector element count raises
VECTOR\_LANE\_INDEX\_OUT\_OF\_RANGE. The faulting instruction
commits no scalar result.
