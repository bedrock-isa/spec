VEXTSQ treats each selected B, W, or L source element as a signed two\textquotesingle{}s-complement
value and sign-extends it into the corresponding Q destination container.  The
governing predicate position associated with each Q container controls that
container.  An inactive container retains its complete previous destination
value.  The operation leaves FLAGS unchanged.
