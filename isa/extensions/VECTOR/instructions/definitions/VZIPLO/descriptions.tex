VZIPLO forms each adjacent result-lane pair from one lane in the lower half of
each input.  In increasing order through those input halves, the even result
lane receives the old destination value and the odd result lane receives the
corresponding Vn value.  The governing predicate retains the corresponding old
destination value in each inactive result lane.
