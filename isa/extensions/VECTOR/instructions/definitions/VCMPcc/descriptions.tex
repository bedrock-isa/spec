VCMPcc compares corresponding active elements under the encoded condition.
The register form reads both elements from (:term:VECTOR.terms.vector_register|plural:). The memory form
reads the right-hand element from the corresponding active VEA location.

B, W, L, and Q forms apply the selected integer condition.
H, S, and D forms apply the selected floating-point condition under the common
floating-point comparison rules.

The destination is a complete predicate image. A significant result bit is
set when its governing bit is set and the selected relation is true. Every
other predicate bit is clear.
