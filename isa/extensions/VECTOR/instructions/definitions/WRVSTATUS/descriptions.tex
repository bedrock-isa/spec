WRVSTATUS writes the architectural 16-bit VSTATUS register from the low 16 bits of the source (:term:base.terms.rn_register:). Reserved VSTATUS bits (:term:base.terms.must_be_zero:), and VLEN encodings 1 and 2 are invalid. An invalid image raises (:ref:base.events.EXCEPTION.INVALID_CONTROL_IMAGE:) and commits no state. A changed image marks vector state modified. WRVSTATUS requires the vector extension.
