Computes the sinh(x) reference over all finite values and signed infinity after DAZ and writes an implementation-bounded S- or D-format approximation under the selected FPTRANSA accuracy contract.

The required FPTRANSA\_ACCURACY contract is \texttt{0x0021}.

\textbf{Special values}\par
\begin{itemize}
\item Infinite or zero source: the result is the source.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item sinh(+0) = +0
\item sinh(-0) = -0
\item sinh(infinity) = infinity with the input sign
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item odd
\item monotonically increasing
\end{itemize}
