After DAZ, computes an implementation-bounded S- or D-format approximation of the log2(x) reference under the selected FPTRANSA accuracy contract. The reference domain includes positive finite values and positive infinity; signed zero is the DZ boundary.

The required FPTRANSA\_ACCURACY contract is \texttt{0x0043}.

\textbf{Special values}\par
\begin{itemize}
\item Zero source: DZ is generated and the result is -infinity.
\item Negative source: NV is generated and the result is the architectural default quiet NaN.
\item Positive infinity: the result is +infinity.
\item Unit source: the result is positive zero.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item log2(+1) = +0
\item log2(signed 0) = -infinity
\item log2(+infinity) = +infinity
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item strictly increasing on the positive domain
\end{itemize}
