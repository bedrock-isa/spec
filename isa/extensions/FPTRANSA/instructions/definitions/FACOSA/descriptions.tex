Computes the $\operatorname{acos}(x)$ reference in radians over finite $x$ with $|x| \le 1$ after DAZ and writes an implementation-bounded S- or D-format approximation under the selected FPTRANSA accuracy contract.

The required FPTRANSA\_ACCURACY contract is \texttt{0x0012}.

\textbf{Special values}\par
\begin{itemize}
\item Source $+1$: the result is positive zero.
\item A finite source with magnitude greater than one, or either infinity, generates NV and produces the architectural default quiet NaN.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item $\operatorname{acos}(+1) = +0$
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item monotonically decreasing on $[-1, 1]$
\item result is in $[0, \pi]$
\end{itemize}
