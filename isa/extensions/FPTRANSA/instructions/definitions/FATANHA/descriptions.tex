Computes the $\operatorname{atanh}(x)$ reference over finite $x$ with $|x| \le 1$ after DAZ and writes an implementation-bounded S- or D-format approximation under the selected FPTRANSA accuracy contract.

The required FPTRANSA\_ACCURACY contract is \texttt{0x0024}.

\textbf{Special values}\par
\begin{itemize}
\item Zero source: the result is the source.
\item Source $+1$ or $-1$ generates DZ and returns infinity with the source sign.
\item A finite source with magnitude greater than one, or either infinity, generates NV and produces the architectural default quiet NaN.
\end{itemize}

\textbf{Exact anchors}\par
\begin{itemize}
\item $\operatorname{atanh}(+0) = +0$
\item $\operatorname{atanh}(-0) = -0$
\item $\operatorname{atanh}(\mathord{\pm}1) = \mathord{\pm}\infty$
\end{itemize}

\textbf{Required properties}\par
\begin{itemize}
\item odd
\item monotonically increasing on $(-1, 1)$
\end{itemize}
