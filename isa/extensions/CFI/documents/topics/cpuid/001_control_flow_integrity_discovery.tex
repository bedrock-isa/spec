\subsection{CFI Extension Discovery}\label{section:cfi-extension-discovery}
Software establishes the (:ref:CFI.cpuid.EXTENSIONS.DIRECTORY.FEATURES.CFI:) extension predicate before using CFILAND or the CFI control registers. The extension
has no implementation-varying architectural parameters.
