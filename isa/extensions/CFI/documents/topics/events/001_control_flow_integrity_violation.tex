\subsection{Control-Flow Integrity Violation}\label{section:cfi-violation}
The (:ref:CFI.events.EXCEPTION.CONTROL_FLOW_INTEGRITY_VIOLATION:) event uses an error frame. ERROR\_CODE values 1,
2, 3, and 4 identify a missing landing marker, a shadow PC mismatch, a shadow code-segment mismatch, and invalid
configured CFI state respectively. A failed check commits neither the control transfer nor CFISP.
