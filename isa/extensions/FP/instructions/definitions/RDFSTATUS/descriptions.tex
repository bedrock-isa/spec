RDFSTATUS reads the architectural 16-bit FSTATUS register, zero-extends it to 64 bits, and writes the result to the destination (:term:base.terms.rn_register:). FSTATUS contains floating-point exception-condition enables, rounding mode, and non-default mode bits. FFLAGS holds accrued (:term:FP.terms.floating_point_exception_flag|plural:). RDFSTATUS requires the floating-point extension.
