\subsubsection{Floating-Point FEA Immediate Forms}
FEA directly declares the register, SP-displaced, PC-displaced, absolute, EXT1, and EXT2 selectors defined for
this profile. Selectors \texttt{0x58}, \texttt{0x5B}, and \texttt{0x5C} are
(:term:base.terms.reserved:). Selectors \texttt{0x5D} and \texttt{0x5E} select \texttt{immsf} and \texttt{immdf}.
The former appends four bytes and the latter eight bytes.

\texttt{immsf} carries the exact IEEE 754 binary32 interchange encoding and \texttt{immdf} carries the exact
binary64 interchange encoding. Either source form is valid for either an S or D instruction. The (:term:base.terms.payload:) format
defines the source format and the instruction suffix defines the operation format. When they differ, operand
evaluation converts the immediate to the operation format under the architectural IEEE 754 environment before the
instruction operation. The conversion uses (:ref:FP.registers.STATE.FSTATUS.RM:); its floating-point exception causes are combined
with the operation\textquotesingle{}s causes and are tested and committed atomically under the (:term:base.terms.ordinary:) precise floating-point fault
rules. An FEA floating-point immediate is never a valid destination.
