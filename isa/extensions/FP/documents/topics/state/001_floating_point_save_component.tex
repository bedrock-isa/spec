\subsection{Floating-Point SAVE Component}
When FP is present, component ID 1 uses bitmap bit 0, offset \texttt{0x00c0}, size \texttt{0x00c0}, and alignment
64. Its initial and reset state is positive zero in F0 through F15 and zero in FFLAGS and FSTATUS. A committed write
that changes any of this state marks the component modified.
