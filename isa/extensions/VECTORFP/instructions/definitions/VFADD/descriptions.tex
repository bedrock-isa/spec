VFADD applies selected floating-point addition independently to each active
vector lane. The governing predicate selects active lanes; an inactive
destination lane retains its previous value.

For H, S, and D elements, each active result is rounded according to the
floating-point environment, and a completed operation
accrues any generated NV, OF, UF, and NX causes in FFLAGS; DZ is unchanged.
If a generated floating-point exception is enabled in any active lane, VFADD
raises FLOATING\_POINT\_EXCEPTION and commits neither destination lanes nor accrued
FFLAGS causes from the faulting operation.
